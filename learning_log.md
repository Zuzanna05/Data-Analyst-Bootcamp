## Dzień 2 - Python: Booleans i instrukcje warunkowe + podstawy SQL

### Python
Dzisiaj przećwiczyłam:
- wartości 'True' i 'False'
- operatory porównania: '>', '<', '>=', '<=', '=='
- instrukcje 'if', 'elif', 'else'
- operatory logiczne 'and', 'or', 'not'
- budowanie prostych reguł biznesowych na podstawie kilku warunków

Ćwiczenia obejmowały m.in:
- sprawdzenie realizacji celu sprzedażowego
- klasyfikację wyników sprzedaży
- przyznawanie premii na podstawie kilku warunków
- identyfikację zamówień wymagających uwagi
- klasyfikację klientów i zamówień

### SQL
Dzisiaj rozpoczęłam pracę z MySQL i MySQL Workbench.

Przećwiczyłam:
- tworzenie tabeli za pomocą 'CREATE TABLE'
- podstawowe typy danych: 'INT', 'VARCHAR', 'DECIMAL'
- dodawanie danych za pomocą 'INSERT INTO'
- pobieranie danych za pomocą 'WHERE'
- używanie operatorów '>', '<', '>='
- łączenie warunków za pomocą 'AND'

Utworzyłam prostą tabelę 'sprzedaz' zawierającą dane o produktach, cenach i liczbie sprzedanych sztuk.

### Najważniejsze wnioski
Instrukcje warunkowe pozwalają podejmować decyzje w kodzie na podstawie danych.
W SQL 'WHERE' pełni podobną rolę - pozwala wybrać tylko te rekordy, które spełniają określone warunki.
Coraz lepiej widzę, jak Python i SQL mogą być wykorzystywane razem w analizie danych.
