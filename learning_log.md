# Data Analyst Bootcamp - Dziennik nauki

## Dzień 1

### Czego się dzisiaj nauczyłam?
Nauczyłam się podstaw Pythona: zmienne, funkcje, operacje arytmetyczne. Zauważyłam pierwsze różnice pomiędzy Pythonem a Javą. Pierwszy raz programowałam w Visual Studio Code (pomijając HTML, JavaScript). Programując w Javie używałam IntelliJ. Pierwszy raz użyłam Jupytera oraz stworzyłam repozytorium używając Git'a. Pierwszy raz zrobiłam commit oraz dodałam repozytorium na GitHub'a poprzez linię komend.

### Co potrafię zrobić samodzielnie?
Potrafię podstawowe operacje oraz tworzenie zmiennych w Pythonie. Potrafię utworzyć funkcje w Pythonie. Potrafię opublikować repozytorium na GitHub przez Git'a.
### Co było dla mnie trudne?
Najtrudniejsze było przestawienie się z Javy na 'lżejszy' język jakim jest Python. Jednakże wydaje się on być językiem zrozumiałym i prostym. Miałam trudności z zrozumieniem funkcji w Pythonie. Trudno było mi również przebrnąć przez instalację Git'a. Trwało to wieki. 

### Co chcę jeszcze powtórzyć?
Chciałabym powtórzyć tworzenie funkcji w Pythonie.
